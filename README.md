# MiniAI

Jednoduchá lokální „AI“ v Pythonu bez externích knihoven.

## Co umí
- reagovat na základní pozdrav,
- říct aktuální čas,
- spočítat jednoduchý matematický výraz přes příkaz `spočítej ...`,
- jednoduchá reakce podle pozitivních/negativních slov.

## Jak spustit náhled
Rychlý náhled bez ručního psaní:
```bash
python3 ai.py --preview
```

Interaktivní režim (chat):
```bash
python3 ai.py
```

## Testy
```bash
python3 -m unittest -v
```
